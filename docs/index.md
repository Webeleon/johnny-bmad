## Getting Started

### Installation

```bash
npm install -g @webeleon/johnny-bmad
```

### Usage

```bash
cd your-bmad-project
johnny-bmad
```

### CLI Options

| Option | Short | Description |
|--------|-------|-------------|
| `--resume` | `-r` | Auto-resume from saved state |
| `--verbose` | `-v` | Enable debug output |
| `--max-iterations` | `-m N` | Max dev-review cycles (default: 10) |
| `--yolo` | `-y` | Auto-complete and auto-commit |
| `--help` | `-h` | Show help message |

### Requirements

- BMAD Project with `_bmad/` folder
- Claude Code CLI (`claude` command in PATH)
- Node.js 18+
- Git (optional, for auto-commits)

## Development

```bash
git clone https://github.com/webeleon/johnny-bmad.git
cd johnny-bmad
bun install

bun run dev          # Watch mode
bun run build        # Build to dist/
bun test             # Run tests
```
