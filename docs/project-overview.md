## Purpose

Johnny BMAD automates the implementation phase of BMAD (Business Model Agile Development) projects. It orchestrates multiple Claude Code sessions with specialized roles to:

1. Check sprint status (SM Agent)
2. Create story files (Story Creator Agent)
3. Implement stories (Dev Agent)
4. Review implementations (Review Agent)
5. Commit changes when approved

## Key Features

- **Multi-Agent Orchestration**: Spawns Claude CLI processes with different models and roles
- **State Persistence**: Saves progress to `.johnny-bmad-state.json` for resume capability
- **Continuous Processing**: Automatically proceeds through epics until complete
- **YOLO Mode**: Auto-complete stories and commits without prompting
- **Verbose Mode**: Labeled output streams for debugging agent interactions
- **Error Recovery**: Automatic retry with 2-second delay on Claude CLI failures
